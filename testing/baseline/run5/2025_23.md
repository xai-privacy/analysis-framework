## Original Question

The meaning that a sentence carries is commonly called a "proposition." Below are two different views on what a proposition is. Alice: The proposition expressed by a sentence is the set of possible worlds in which that sentence is true. For example, the sentences "Suchul is tall" and "Suchul is a student" express different propositions, since the set of possible worlds where Suchul is tall and the set of possible worlds where Suchul is a student are different sets. If a certain sentence is true in every possible world, then the proposition it expresses is the set of all possible worlds. For instance, the sentence "3 is odd or not odd" expresses the proposition which is the set of all possible worlds. Bob: A proposition is a kind of ordered pair. For example, the proposition expressed by the sentence "3 is odd" can be understood as an ordered pair composed of the object referred to by "3" and the property referred to by "is odd." If we let the object referred to by "3" be m and the property referred to by "is odd" be F, then the proposition expressed by "3 is odd" is <m, F>. As another example, the sentence "Suchul loves Heeyoung" expresses a proposition that can be understood as an ordered triplet composed of the object referred to by "Suchul," the object referred to by "Heeyoung," and the binary relation referred to by "loves." If the object referred to by "Suchul" is a, the object referred to by "Heeyoung" is b, and the binary relation referred to by "loves" is r, then the proposition expressed by "Suchul loves Heeyoung" is <a, b, r>. <question> Which of the following can be correctly inferred? Choose as many as applicable from <statements>. <statements> (a). Both Alice and Bob would agree that, provided "Suchul" and "Heeyoung" refer to different objects, the sentences "Suchul loves Heeyoung" and "Heeyoung loves Suchul" express different propositions. (b). A person who believes that the sentences "A round square exists" and "3 is odd and not odd" have different meanings would oppose Alice's view. (c). If "Morning Star" and "Evening Star" refer to the same object, then someone who believes that the sentences "The Morning Star is beautiful" and "The Evening Star is beautiful" have different meanings would oppose Bob's view. <choices> ① (b) ② (c) ③ (a), (b) ④ (a), (c) ⑤ (a), (b), (c)

## Original Answer

**Answer choice:** 5

All of (a), (b), and (c) are valid inferences, so the answer is ⑤.
