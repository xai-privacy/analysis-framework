## Other prompting techniques

In short, none of the prompting techniques that I tried improved the result. Most either selected answer choice 4 or answer choice 3, but none ever got it correct. Below is a short summary of the responses and outputs for each technique. The complete outputs are in 2021_14_prompting.json, as I didn't want to paste them all here.

**Zero-shot:** The same as the baseline from above, but with slightly more padding. It prompts the model with the zero-shot prompt that I used in `strategies.py` from the LEET-Arg paper (Solve the problem and provide explanations...), and also instructs the model to output an answer 1-5, directly. The output was similar both in reasoning and in answer choice, as it selected choice 4.

**Zero-shot CoT:** The output for Zero-shot CoT explained that (a) and (c) were correct, while (b) was not. For answer choice (c), it explained that "Bob2's position is that not saving the child is an act, but not giving the gift to B is not an act." This is a correct line of thinking, but the model failed to realize that since this is true, choice (c) must be false.

**Graph-of-Thoughts:** Although the final answer output was stated as answer choice 3, the model seemed to give reasoning that implied it believed answer choice 4 was correct. This means the model failed to correctly aggregate it's own thoughts, although in the end it didn't matter as both 3 and 4 are incorrect answer choices.

**Self-consistency:** Self consistency ran 5 different thought processes, then the most common one was taken as the result. 3 of the thought processes believed answer choice 3 was correct, and 2 believed answer choice 4 was correct. So, at no point did it consider answer choice 1 correct.
