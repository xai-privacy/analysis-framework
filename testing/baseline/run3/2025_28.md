# Question 2025_28

## Original Question

Empirical studies examining the effects of differences in emotional facial expressions on memory typically involve showing participants photographs of faces displaying negative expressions (such as anger or crying) or emotionally neutral, expressionless faces. After a certain period of time, participants are then asked to identify which faces they have seen before from among a set of various photographs. At this point, differences in emotional expressions between the photos shown during the learning phase and those shown during the memory test phase can cause differences in memory performance. Therefore, to examine the effect of emotional expressions on facial memory, changes in memory rates due to mismatches in emotional expressions between the learning and test phases must be considered. For this purpose, the following <hypotheses> were tested through the following <experiments>.<Hypotheses> A: The memory rate for faces with negative expressions is higher than that for faces with neutral expressions. B: The influence of expression congruence between the learning and test phases on memory rate is greater than the difference in memory rates between negative and neutral expressions.<Experiments> Experiment 1: Participants were randomly divided into two groups. One group learned faces with negative expressions, and the other group learned faces with neutral expressions. In the test phase, both groups were tested on memory using facial expressions identical to those shown during the learning phase. Experiment 2: All participants learned faces with negative expressions. During the test phase, they were randomly divided into two groups; one group was tested with faces showing negative expressions, while the other group was tested with faces showing neutral expressions. <question>  Which of the following <statements> is/are true when evaluating the above passage? <Statements> (a) If the results of Experiment 1 show that the memory rates of the two groups are similar, Hypothesis A is weakened. (b) If the results of Experiment 2 show that the memory rates of the two groups are similar, Hypothesis A is weakened. (c) If the results of Experiment 1 show that the memory rates of the two groups are similar, and the results of Experiment 2 show that the group tested with negative expressions has a higher memory rate than the group tested with neutral expressions, then Hypothesis B is strengthened. <choices> ① (a) ② (b) ③ (a), (c) ④ (b), (c) ⑤ (a), (b), (c)

## Original Answer

**Answer choice:** 3

Since only (a) and (c) are correct, the answer is ③.

## LLM Response

Answer-④

Rationale 1. If the results of Experiment 1 show that the memory rates of the two groups are similar, then Hypothesis A cannot be supported, because if the memory rate for faces with negative expressions is lower than that for faces with neutral expressions, then the memory rates of the two groups should not be similar.

Rationale 2. If the results of Experiment 2 show that the memory rates of the two groups are similar, then Hypothesis B cannot be supported, because if the influence of expression congruence between the learning and test phases on memory rate is not greater than the difference in memory rates between negative and neutral expressions, then the memory rates of the two groups should not be similar.

Rationale 3. If the results of Experiment 1 show that the memory rates of the two groups are similar, and the results of Experiment 2 show that the group tested with negative expressions has a higher memory rate than the group tested with neutral expressions, then Hypothesis B is strengthened, because it suggests that the influence of expression congruence between the learning and test phases on memory rate is indeed greater than the difference in memory rates between negative and neutral expressions.
